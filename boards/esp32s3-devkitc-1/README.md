# ESP32-S3-DevKitC-1 (N16R8) — boot assets

## `bootloader.bin`

A standard ESP-IDF v5.5.1 second-stage bootloader for the ESP32-S3, built from
`smart_home_idf`'s configuration: 16 MB flash, octal PSRAM, **no** secure boot or
flash encryption, app rollback **disabled**.

It is committed only so `esp_sdk.sh --build` and the esp32sim smoke test
are reproducible without an ESP-IDF install. It is not the SDK's final bootloader:
Phase 0 replaces it with a reproducible build that enables
`CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE` (see [docs/BOOT.md](../../docs/BOOT.md)).

Source: ESP-IDF v5.5.1 (Apache-2.0), `components/bootloader`, built for
`esp32s3` with the project's `sdkconfig`.

## `partition-table.bin`

Not committed: generated by `esp_sdk.sh --build` for the simulation layout
(bootloader 0x0, table 0x8000, factory app 0x10000). Board tables for real
products are generated from `board.dts` in Phase 2.
